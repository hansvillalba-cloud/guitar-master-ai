# Avisos de componentes de terceros

## alphaTab

Guitar Master AI carga alphaTab 1.9.0 desde jsDelivr para importar, renderizar y reproducir archivos Guitar Pro. alphaTab es un proyecto de código abierto distribuido bajo Mozilla Public License 2.0 (MPL-2.0).

- Proyecto y documentación: https://www.alphatab.net/
- Código fuente: https://github.com/CoderLine/alphaTab
- Paquete utilizado: https://www.npmjs.com/package/@coderline/alphatab

La aplicación no incluye ni distribuye canciones comerciales. Los archivos que el usuario importe son de su propiedad o deben contar con los permisos correspondientes.


Guitar Master AI V1.6 incluye ejercicios y composiciones cortas originales creadas para esta aplicación. No se incluyen grabaciones ni tablaturas comerciales de las bandas mencionadas como referencias de género.
